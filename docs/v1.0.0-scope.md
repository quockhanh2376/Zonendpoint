# Zonendpoint v1.0.0 product scope

This scope supersedes earlier UI language and theme requirements that conflict with v1.0.0.

## Product surface

- All text written and controlled by Zonendpoint is English: screens, menu items, buttons, tooltips, accessibility labels, statuses, validation, errors, notifications, and installer content.
- Native Windows dialogs may use the operating system's display language. User-provided paths and file names are data, not translated product copy.
- The v1.0.0 interface starts in Light theme on first launch and provides an accessible Light/Dark toggle that persists the user's choice across app restarts.
- English/Vietnamese language selection remains out of scope; do not show a language selector or translated placeholder.
- Do not add an i18n library or theme framework for v1.0.0. Reuse the app's CSS tokens and local storage.
- Real-time protection remains off in this MVP; UI copy must not imply that protection is active.
- Initial deployment target is an internal company pilot (Zon confirmed2026-11-07). This does not imply approval for public feeds/APIs, uploads, licensing implementation or a signed/public release.

## Backlog after v1.0.0

- English/Vietnamese language selection.
- Feed enrichment/client IOC sync, Guard/Battle Mode, firewall/IP response and allow-policy management, quarantine/restore, SQLCipher/DPAPI migration, process hardening, optional BYOK AI assistance, SecConnect/licensing. These are design backlog with prerequisites in [roadmap.md](roadmap.md) and [implementation-plan.md](implementation-plan.md); no new feature implementation is authorized merely by listing it.

These items are later-version backlog only. They are not v1.0.0 controls or placeholders.

## Current UI audit

- `src/App.tsx` had Vietnamese labels, explanatory text, progress and summary text, and status names. They are now English.
- `index.html` exposed the starter template title and Vite icon; the document title is now `Zonendpoint` and the template icon reference is removed.
- `src/App.css` defines Light/Dark color tokens. The theme toggle lives on the main screen and persists the choice. No language control is present. The native picker is supplied by Windows and may follow the OS language.
- App-owned target menu, scan controls/statuses and unsigned installer now exist; apply English-only copy to these and future surfaces. Native OS-owned dialogs can follow Windows language. Historical UI notes above describe changes, not unimplemented requirements.

## Approved Quick scan/x64 update — 2026-11-07
Initial primary action is Quick scan for13 fixed Windows core files plus the native System32/drivers subtree. Native GetSystemDirectoryW supplies the system root; this is a limited file scan, not a full-system/memory/boot integrity verdict. Chosen native File/Folder uses Scan; target menu Quick scan returns to system targets. Existing All Good/Stop/cancel/error guarantees remain. Application Windows builds/packages support x86_64 only; file contents are not filtered by architecture.
