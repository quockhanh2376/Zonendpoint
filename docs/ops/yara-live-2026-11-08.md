## 6. Update V-15: Removal of Heuristic `SUSP_` Rules

### 6.1. Root Cause & Decision
During Qeen's live validation on Windows (Task Q-12), a False Positive occurred on `C:\Windows\System32\winevt\Logs\Windows PowerShell.evtx`, triggering `YARA.SIGNATURE_BASE_SUSP_PS1_JAB_Pattern_Jun22_1.UNOFFICIAL`.
Root cause: the rule checks base64-encoded single-character variable assignments with condition `filesize < 30MB and 1 of them` without filetype or magic byte constraints. Standard Windows PowerShell event logs naturally record PowerShell command strings matching this pattern.

Zon approved removing **all** rules with `SUSP_` in their identifier from the live ruleset.
